# ParcelAI 📦

AI-powered cadastral mapping from drone imagery. ParcelAI is a modern web application designed to help surveyors and land management teams process, analyze, and manage drone orthomosaics.

## ✨ Features

- **Automated Parcel Mapping:** Upload your drone imagery and let AI extract parcel boundaries.
- **Interactive Dashboard:** View, analyze, and manage extracted parcels on an interactive map.
- **Discrepancy Detection:** Automatically flags potential boundary discrepancies for officer review.
- **GeoJSON Support:** Standardized formats for easy integration with existing GIS workflows.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Vanilla CSS
- **Mapping:** Leaflet, React-Leaflet
- **Backend:** Python (FastAPI/Models)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/munazzaghazali7-hash/ParcelAI.git
   ```

2. Navigate to the project directory:
   ```bash
   cd ParcelAI
   ```

3. Install frontend dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:5173`.
